Step-by-step guide

How to turn any bootcamp page into a downloadable, trackable SCORM 1.2 package — from cloning the repo on Windows to uploading to Chamilo or Cornerstone.

SCORM 1.2 Windows Git + Python Cornerstone / Chamilo
Phase 1 — One-time setup
Install the tools
1
Install Git for Windows

Git lets you download (clone) the repository to your computer. Download from git-scm.com/download/win → run the installer → keep all defaults → Finish.

Command Prompt — verify
C:\Users\Usuario> git --version
git version 2.54.0.windows.1
Tip: If you see "git is not recognized", close and reopen Command Prompt after installing.
2
Install Python

Python runs the packaging script. Download from python.org/downloads → run installer → check "Add Python to PATH" → Install.

Command Prompt — verify
C:\Users\Usuario> python --version
Python 3.14.5
Tip: During Python install, tick "Add Python to PATH" before clicking Install. Without it, the command won't be found.
Phase 2 — Get the files
Clone the repository
3
Open Command Prompt

Press Windows key + R → type cmd → press Enter. Or search "Command Prompt" in the Start menu.

4
Clone the repository

This downloads all the bootcamp files to your computer. Only needed once — when you need updates later, use git pull.

Command Prompt

5
Enter the repository folder
Command Prompt
C:\Users\Usuario> cd bootcampLearningArchitech
C:\Users\Usuario\bootcampLearningArchitech>
Tip: In File Explorer, navigate to C:\Users\Usuario\bootcampLearningArchitech, click the address bar, type cmd and press Enter — it opens Command Prompt directly in that folder.

Phase 4 — Test before uploading
Validate in SCORM Cloud (free)
9
Create a free SCORM Cloud account

Go to app.scorm.com → Sign Up → the free plan gives 10 test registrations. No credit card needed.

10
Import the zip

In SCORM Cloud: click Add Content → Import a SCORM package → drag the zip file from your dist folder.

Phase 5 — Go live
Upload to your LMS
12
Chamilo (you already have this)

Chamilo supports SCORM 1.2 natively — no extra setup needed.

  • Log into Chamilo as admin
  • Go to a course → Content → Learning paths
  • Click Import a SCORM package
  • Upload the zip → it appears as a trackable lesson
  • Reports: Course → Tracking → see each learner's score, status and interactions
13
Cornerstone OnDemand

Enterprise LMS — requires an org account. Upload procedure once you have access:

  • Admin → Edge Import or Course Catalog → Add Course
  • Select Online Course → Upload SCORM
  • Upload the zip → set availability → publish
  • Learner reports: Reporting → Transcript or Custom Reports
Note: Test everything in Chamilo first — the SCORM tracking is identical. When you're ready for Cornerstone, the same zip files work without any changes.
Phase 6 — Dispatch & xAPI Tracking
Share via Dispatch and track with Veracity LRS
14
Create a Destination in SCORM Cloud

In SCORM Cloud, go to Dispatch (top menu) → Destinations → New Destination. Give it a name (e.g. "Moodle Campus") and save.

SCORM Cloud → Dispatch → Destinations
+ New Destination
Moodle Campus
Destination ID generated automatically
15
Create the Dispatch — select course + destination

Go to Dispatch → Dispatches → New Dispatch. Select the course from the dropdown, then select the destination you just created. Click Create.

  • Click the Courses dropdown — select your course (e.g. AI Literacy)
  • Click the Destinations dropdown — select "Moodle Campus"
  • Click Create Dispatch
16
Download the Dispatch SCORM 1.2 package

In the Dispatch list, click your dispatch → Share → Download SCORM 1.2 package. This zip reports data back to SCORM Cloud's LRS — not to the LMS.

Important: Use THIS Dispatch zip when uploading to Moodle or Chamilo — NOT the original zip from your dist/ folder. The Dispatch zip tunnels xAPI data back to SCORM Cloud.
17
Upload to Moodle: Add activity → SCORM

In your Moodle course, turn editing on and add a SCORM activity with the Dispatch zip.

  • Turn editing on → Add an activity or resource
  • Select SCORM package → click Add
  • Give it a name → drag the Dispatch zip into the Package file area
  • Save and display — learners open it and data flows to SCORM Cloud
Note: Moodle's own gradebook shows completion/score from the SCORM wrapper. The full xAPI detail — actor, verb, raw score, timestamps — lives in SCORM Cloud's LRS under Dispatch → Registrations.
18
Optional: pipe xAPI data to Veracity LRS (lrs.io — free)

Veracity LRS (lrs.io) is a free hosted xAPI Learning Record Store. Connect it to SCORM Cloud so every statement also lands in your own LRS.

  • Create a free account at lrs.io → note the LRS endpoint URL and credentials
  • In SCORM Cloud: Applications (top menu) → xAPI Pipes → Add Pipe
  • Paste the Veracity LRS endpoint, username and password → Save
  • From now on, every xAPI statement SCORM Cloud receives is also forwarded to Veracity in real time
