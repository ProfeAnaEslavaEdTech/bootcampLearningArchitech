01 Why WCAG 2.2 and not WCAG 2.1? ¿Por qué WCAG 2.2 y no WCAG 2.1?

WCAG 2.2 (W3C, October 2023) adds 9 new criteria on top of WCAG 2.1. The most relevant for digital instructional design: WCAG 2.2 (W3C, octubre 2023) añade 9 criterios nuevos sobre WCAG 2.1. Los más relevantes para diseño instruccional digital:

CriterionCriterio LevelNivel What it requiresQué exige
2.4.11 Focus Not Obscured AA ✦ The focused element is not completely hidden by another (e.g. sticky header)El elemento con foco no queda completamente oculto por otro (p.ej. header sticky)
2.5.7 Dragging Movements AA ✦ Every drag function has a non-drag alternativeToda funcionalidad de arrastre tiene alternativa sin arrastre
2.5.8 Target Size Minimum AA ✦ Touch target area ≥ 24×24 CSS pxÁrea de toque ≥ 24×24 CSS px
3.2.6 Consistent Help AA ✦ Help mechanism appears in the same position on every pageEl mecanismo de ayuda aparece en la misma posición en todas las páginas
3.3.7 Redundant Entry A ✦ Don't ask for information already provided in the same processNo solicitar información ya proporcionada en el mismo proceso
3.3.8 Accessible Authentication AA ✦ Don't require a cognitive test to authenticate without an alternativeNo requerir test cognitivo para autenticarse sin alternativa

✦ = New criterion in WCAG 2.2 (not in WCAG 2.1)Criterio nuevo en WCAG 2.2 (no presente en WCAG 2.1)

02 POUR Principles Principios POUR
  • PerceivablePerceptible — Information can be perceived through any sense.La información puede percibirse por todos los sentidos.
  • OperableOperable — Controls and navigation work with keyboard and pointer.Los controles y la navegación son accionables con teclado y puntero.
  • UnderstandableComprensible — Language and behaviour are predictable.El lenguaje y el comportamiento son predecibles.
  • RobustRobusto — Content works with current and future assistive technologies.El contenido funciona con tecnologías de asistencia actuales y futuras.
03 Audit process — 6 steps Proceso de auditoría — 6 pasos
1

PreparationPreparación

Define the scope (unique pages), note the canonical URL, choose your user agent (Chrome + NVDA or Safari + VoiceOver), download the WCAG Quick Reference.Define el alcance (páginas únicas), anota la URL canónica, elige agente de usuario (Chrome + NVDA o Safari + VoiceOver), descarga WCAG Quick Reference.

2

Automated inspection (~30–40 % of issues)Inspección automatizada (~30–40 % de problemas)

axe DevTools (Chrome/Edge extension) · WAVE (webaim.org/wave) · Lighthouse (DevTools → Lighthouse tab). Export the report.axe DevTools (extensión Chrome/Edge) · WAVE (webaim.org/wave) · Lighthouse (DevTools → Lighthouse tab). Exporta el informe.

3

Manual keyboard checkVerificación manual con teclado

Tab / Shift+Tab · Enter / Space · Arrow keys · verify skip link, visible focus, no focus trap.Tab / Shift+Tab · Enter / Espacio · teclas de flecha · verificar skip link, foco visible, sin trampa de foco.

4

Screen readerLector de pantalla

NVDA + Firefox (Windows, free) or VoiceOver + Safari (macOS/iOS). Navigate by headings, links, forms. Verify alt text, aria-live, accessible names.NVDA + Firefox (Windows, gratis) o VoiceOver + Safari (macOS/iOS). Navega por encabezados, links, formularios. Verifica alt text, aria-live, nombres accesibles.

5

Colour contrastContraste de color

Colour Contrast Analyser (TPGi, free). Normal text ≥ 4.5:1 · Large text ≥ 3:1 · UI components ≥ 3:1.Colour Contrast Analyser (TPGi, gratis). Texto normal ≥ 4.5:1 · Texto grande ≥ 3:1 · Componentes UI ≥ 3:1.

04 Most common fixes Correcciones más frecuentes

Skip Link — 2.4.1 Bypass Blocks (Level A)

BEFORE — Fail 2.4.1ANTES — Fallo 2.4.1
<body>
  <nav>…nav completa…</nav>
  <main>…contenido…</main>
</body>
AFTER — ConformantDESPUÉS — Conforme
<body>
  <a href="#main-content"
     class="skip-link">
    Skip to main content
  </a>
  <nav>…nav completa…</nav>
  <main id="main-content">…</main>
</body>

aria-live — 4.1.3 Status Messages (Level AA)

BEFORE — No announcementANTES — Sin anuncio
<div id="panelHead"></div>
<!-- textContent changes silently -->
AFTER — AnnouncedDESPUÉS — Anunciado
<div id="panelHead"
     aria-live="polite"
     aria-atomic="true"></div>
<!-- VoiceOver/NVDA announces change -->

06 Practical exercise Ejercicio práctico
  1. Choose a URL from an e-learning project or portfolioElige una URL de un proyecto e-learning o portfolio
  2. Run axe DevTools and export the reportEjecuta axe DevTools y exporta el informe
  3. Navigate the whole page keyboard-only (no mouse) for 5 minutesNavega la página entera solo con teclado (sin ratón) durante 5 minutos
  4. Check the contrast of the 3 main text coloursVerifica el contraste de los 3 colores de texto principales
  5. Activate NVDA or VoiceOver and navigate by headingsActiva NVDA o VoiceOver y navega por encabezados
  6. Document each finding in the Step 6 tableDocumenta cada hallazgo en la tabla del Paso 6
  7. Propose a code fix for the 2 most serious problemsPropón la corrección de código para los 2 problemas más graves

Success criterion:Criterio de éxito: You have identified at least 1 Level A failure and proposed its fix with before/after code. Has identificado al menos 1 fallo Nivel A y propuesto su corrección con código antes/después.
