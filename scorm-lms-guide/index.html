Quick reference

Build the zip

  • PowerShell: cd bootcampLearningArchitech
  • python scripts/pack-scorm.py ai-literacy
  • Output: dist/ai-literacy.zip

Test in SCORM Cloud

  • app.scorm.com → Library
  • + Add Content → upload zip
  • Launch → verify completion

Deploy to LMS

  • Dispatch → download zip
  • Moodle: Add activity → SCORM
  • Chamilo: Learning Paths → Import SCORM

Track learners

  • SCORM Cloud → xAPI LRS
  • Veracity: lrs.io (free)
  • Pipe: SCORM Cloud → Veracity
