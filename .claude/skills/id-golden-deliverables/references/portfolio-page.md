# Portfolio Project Page — golden format

Short, scannable project index (one page). Mirrors the tmsid portfolio blocks.

## Structure
1. **Title** — Project name + descriptive subtitle (e.g., "Digital Wellness: Staying
   Healthy, Happy and Productive in a Digital World").
2. **The Problem** — 2–4 sentences: the business/performance problem and the goal.
3. **Tools used** — comma-separated list (e.g., Articulate Rise 360, Three.js (WebGL),
   xAPI/SCORM, Canva, Adobe Podcast, Google Workspace).
4. **Deliverables (links)** — one link per artifact:
   - Design Document
   - Storyboard / Design Script
   - E-learning course / live demo
   - 3D Simulator (live URL)
   - Facilitator's Guide (if blended/VILT)
   - Knowledge Check, Effectiveness plan, Glossary
5. **Art. 50 disclosure** footer.

## Style
- Keep it tight; this is the entry a reviewer scans first.
- Use real, working links (prefer a stable host; for GitHub-hosted HTML use a commit-pinned
  raw.githack URL or GitHub Pages).
- Default language English (portfolio standard); offer an ES version.
