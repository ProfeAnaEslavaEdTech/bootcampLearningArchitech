# Design Document — golden format

Two-column table. Left column = dark navy (#1F3448) label cells, white bold text.
Right column = body. Title on top: "Design Document" + "Training Title: …".
Footer: "<Project> — Design Document — Page X of Y".

## E-learning schema (self-paced) — use for Rise/Storyline courses
| Label | Content |
|---|---|
| **Business Purpose / Business Goal and Problem** | The business problem in plain terms + the measurable goal (e.g., "100% of operators perform Step 5 on a single layer, zero error"). Tie to defects, rework, line stoppages, compliance. |
| **Target Audience** | Who, their context, prior experience, language(s), environment (e.g., regulated MedTech floor). |
| **Training Time** | e.g., "15–20 minute e-learning" (+ L3 supervised practice if blended). |
| **Training Recommendation** | Delivery method + why (distributed workforce → e-learning scales). For blended, state "BLENDED" and name the L2 and L3/L4 components. |
| **Deliverables** | Bullet list: storyboard/script, e-learning course, 3D simulator, knowledge check, effectiveness plan, glossary, facilitator guide + checklist (if blended). |
| **Learning Objectives** | "By the end … learners will be able to:" Terminal objective(s) + Enabling objectives. Measurable verbs. |
| **Training Outline** | Introduction (Welcome, Navigation, Learning Objectives) → Topics (each with a Knowledge Check) → Assessment → Summary → Congratulations. |
| **Assessment Plan** | Critical items (100%, Zero-Gate), item types, pass rule, unlimited attempts. Add the honest L2/L3/L4 framing. |

## VILT / ILT schema (instructor-led) — use for facilitator-led sessions
Same table, with these label changes/additions:
| Label | Content |
|---|---|
| **Business Goal and Problem** | As above. |
| **Target Audience** | As above. |
| **Learning Objectives** | **Terminal LOs** and **Enabling LOs** (two sub-blocks). |
| **Training Recommendation** | **Delivery Method:** (e.g., Zoom / in-person). **Approach:** activities, facilitator supported by producer, notes in the facilitator guide. |
| **Training Time** | e.g., "Around 60 minutes". |
| **Deliverables** | Slide deck with links, Facilitator's Guide, (polls/Mentimeter, etc.). |
| **Training Outline** | Numbered agenda: Introduction → Icebreaker → core topics with breakouts/polls/discussion → Q&A → Conclusion (summary, resources, appreciation). |
| **Assessment Plan** | **Level 2 Assessment:** (observation in polls/discussions). **Level 3 Assessment:** (replies to action plans / on-the-job). |

## Blended
Produce the e-learning schema for the self-paced part AND a Facilitator Guide (see
`facilitator-guide.md`) for the instructor-led L3/L4 part. The Design Document's Training
Recommendation must say "Delivery method: BLENDED" and describe both parts.
