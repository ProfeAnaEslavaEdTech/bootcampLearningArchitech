# Facilitator Guide (VILT/ILT) + L3/L4 checklists — golden format

For the instructor-led component (blended projects: the L3 supervised practice on the floor,
and L4 results tracking).

## Facilitator Guide structure
1. **Session overview** — title, duration, audience, prerequisites (e.g., "learner passed
   the e-learning Zero-Gate"), materials, room/floor setup.
2. **Facilitator notes per segment** — a table: Segment · Time · What the facilitator does ·
   What the learner does · Slide/prop · Notes (producer support, links checked beforehand).
3. **Observation / practice** — how the trainer runs the supervised practice at the station.

## L3 — Supervised practice observation checklist (Step-7, 6 criteria)
A yes/no checklist the trainer completes while observing the real stitch. Example for
SOP-100-AX Step 5 (adapt criteria to the procedure):
| # | Criterion | Pass? |
|---|---|---|
| A | Anchor knot located; counted 5 loops up (column no. 8) | ☐ |
| B | Locking stitch worked on a SINGLE layer (Layer 2 untouched) | ☐ |
| C | Correct thread path (right→left, around the loop) | ☐ |
| D | Exit point correct (left of the loop) | ☐ |
| E | No loose loops | ☐ |
| F | No damage to the fabric/piece | ☐ |
Validation only when ALL criteria pass with zero error. Record: first-pass %, retries,
errors per criterion.

## L4 — Results tracking sheet
Track over time: "two-layer" defect rate and associated line stoppages (before vs after).
A sustained decrease in both confirms transfer to the real work environment.

## Rules
- The checklist is the real measure of "applying the change in practice" — not the e-learning.
- Keep bilingual EN/ES if asked. Art. 50 footer.
