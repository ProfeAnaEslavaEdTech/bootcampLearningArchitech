Ocean Ink

The design system behind CUXedTech and Ana Eslava's digital learning portfolio. Three visual tiers, a complete token set, and clear rules for how colour, type, spacing, states and motion work together across identity, instructional and editorial contexts.

Visual register

Three identity tiers

Ocean Ink operates across three tiers. Use the tier that matches the context. Never mix tier roles within the same interface component.

Tier 1

Identity

Portfolio, CV, LinkedIn and brand-facing pages. Quiet, classic and minimal. Indigo Blue as the structural accent, Deep Blue for headings, Gold used sparingly. Fraunces for display headings; Inter for body and UI.

Tier 2

Instructional

Learning content and instructional interfaces. Fixed semantic colours for Mastered, Needs Review, In Progress and Locked states. State colours carry meaning — they are never decorative. Text labels and glyphs always accompany colour.

Tier 3

Editorial

Case studies, documentation hubs and product landing pages. More expressive than the identity tier — Gold accent may be used more prominently, typographic emphasis and bolder layout arrangements are permitted, while the Ocean Ink token system stays intact.

Foundation

Spacing scale

An 8 px base unit. Apply these tokens consistently to margins, padding, gaps and component internal spacing. Do not introduce arbitrary intermediate values.

Foundation

Typography

Fraunces (variable optical-size serif) for display and headings. Inter for body, UI labels and data. Both loaded from Google Fonts; always declare the full fallback stack in implementation.

Components

Component states

Every interactive component must implement all six states. A missing state means the component behaves unexpectedly in that context. Test focus rings in both light and dark themes.

Default base

Resting appearance. Full opacity. --primary fill.

Hover :hover

Subtle lift and brightness shift. cursor: pointer.

Focus :focus-visible

2 px --focus-ring outline, 2 px offset. Keyboard only.

Active :active

92 % opacity, scale(0.98) transform, deep fill.

Disabled [disabled]

--muted text, 50 % opacity. cursor: not-allowed.

Error aria-invalid

--state-error surface. Pair with icon and text message.

Foundation

Motion & animation

Animate opacity and transform only. Always respect prefers-reduced-motion. Click a card to preview its timing.

Always wrap motion in:
@media (prefers-reduced-motion: no-preference) { … }
Provide an instant or opacity-only fallback for users who have requested reduced motion.
