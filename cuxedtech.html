Origin

Born from a masterclass.
Finished by doing.

The UX Writing skill in this plugin was built as a direct application of what was taught — not taken from a slide, but rebuilt into something reusable. That is what honouring a teacher looks like.

Formative attribution — UX Writing skill

The UX Writing and conversational design principles in this plugin derive from the masterclass, course and talk delivered on 6 November 2026 by Antonio Estévez Funes, Conversational Designer at BBVA, at the Instructional Design School of the Universitat Politècnica de València (UPV).

The session covered the difference between copywriting and UX Writing; the three principles (clear, consistent, useful); voice versus tone; plain language; CTA patterns; error feedback; and the relationship between UX Writing and WCAG accessibility.

The synthesis, structure, Travel Good case study, and all extensions are Ana Eslava-Graterol's own adaptation work — not a transcription, and not reviewed or endorsed by Antonio Estévez Funes, BBVA, or the UPV.

The A/B test data point (33% → 59% login comprehension) was shared publicly during the session. If cited outside this portfolio, attribute it to what was shared in the session, not to CUXedTech or to independent verification.

Try CUXedTech

Two ways to use it.

CUXedTech runs in ChatGPT (web, no install) and in Claude Code (download and install). Both versions share the same 12-dimension evaluation framework.

◆ ChatGPT — no install

Evaluate any digital experience

Open ChatGPT, search for @CUXedTech in the plugin directory, then paste your URL and your evaluation request.

Example prompt "Evaluate [your URL] using the relevant CUXedTech UX quality criteria. Focus on UX Writing, accessibility and information architecture."
Plugin URI (paste inside ChatGPT)
plugin://cuxedtech@openai-curated-remote?remotePluginId=plugins_6aee1736a6cc81918d7de246a1c85b80
Open ChatGPT (opens in a new tab) →

Visitors may need to find and select @CUXedTech in the plugin directory once inside ChatGPT.

◇ Claude Code — download & install

Use it as slash commands

Download the plugin zip, extract it, and place the skills/ folder in your Claude Code project. Skills become available as slash commands.

Available commands /ux-writing-travel-good
/ocean-ink-design-system
/ux-quality-framework
/ai-disclosure-suite

unzip cuxedtech-plugin.zip -d .claude/plugins/cuxedtech
