Origin

Born from a masterclass.
Finished by doing.

The UX Writing skill in this plugin was built as a direct application of what was taught — not taken from a slide, but rebuilt into something reusable. That is what honouring a teacher looks like.

Formative attribution — UX Writing skill

The UX Writing and conversational design principles in this plugin derive from the masterclass, course and talk delivered on 6 November 2026 by Antonio Estévez Funes, Conversational Designer at BBVA, at the Instructional Design School of the Universitat Politècnica de València (UPV).

The session covered the difference between copywriting and UX writing, the three principles (clear, consistent, useful), voice vs. tone (four Nielsen Norman dimensions), plain language, CTA patterns, error feedback, and the relationship between UX writing and WCAG accessibility.

The synthesis, structure, Travel Good case study, and all extensions in the plugin are Ana Eslava-Graterol's own adaptation work — not a transcription of the session, and not a deliverable reviewed or endorsed by Antonio Estévez Funes, BBVA or the UPV.

The A/B test data point (33% → 59% login comprehension, Love ISDIN) was shared publicly during the session. If cited outside this portfolio, attribute it to what was shared in the session, not to CUXedTech or to independent verification.

What's inside

Five skills. One framework.

Each skill covers a distinct discipline and uses the CUXedTech 12-dimension evaluation framework as its backbone.

✍️

UX Writing & Content Design

Analyses interfaces, drafts and audits microcopy, CTAs, errors, onboarding, empty states and notifications. Applies the three principles (clear, consistent, useful), Grice's maxims and WCAG. Includes the Travel Good style guide as a worked case.

Built after Antonio's masterclass

Ocean Ink Design System

Applies Ana's personal brand identity — Indigo Blue, Warm Gold, Deep Blue — to every visual deliverable. WCAG 2.1 AA verified. Light and dark themes. Fraunces + Inter typography. Governs HTML artifacts, Canva, Figma and presentation work.

Ana's own system · MLLDE-aligned

Integrated UX Quality Framework

Coordinates across all 12 UX evaluation dimensions: user research, UX strategy, IA, interaction design, UI, UX writing, accessibility, responsive design, multilingual UX, technical experience and usability evaluation.

What to expect

What CUXedTech evaluates.

The 12-dimension framework covers the full digital experience — from strategy to microcopy. Tell it which dimensions matter most for your project.

Twelve evaluation dimensions

Share a URL, a screen, a component or a user journey. CUXedTech identifies what works, what creates friction, and what to prioritise.

1

User research & UX strategy

User needs, goals, context of use, product objectives, value proposition, success criteria.

2

Information architecture & interaction design

Navigation, labels, hierarchy, discoverability, component behaviour, feedback loops.

3

UI, UX Writing & accessibility

Visual identity, microcopy, CTAs, error messages, plain language, WCAG POUR principles.

4

Responsive, multilingual & usability

Breakpoints, touch targets, language and market adaptation, usability heuristics and task success.

Try CUXedTech

Two ways to use it.

CUXedTech runs in ChatGPT (web, no install) and in Claude Code (download & install). Both versions share the same 12-dimension evaluation framework.

🟢

ChatGPT — no install

Open ChatGPT and search for @CUXedTech in the plugin directory. Paste your website URL and ask it to evaluate your digital experience using the relevant UX quality criteria.

Example prompt:
"Evaluate [your URL] using the relevant CUXedTech UX quality criteria. Focus on UX Writing, accessibility and information architecture."
Open ChatGPT →
Visitors may need to find and select @CUXedTech in the plugin directory once inside ChatGPT.
🔵

Claude Code — download & install

Download the plugin zip, extract it, and place the skills/ folder in your Claude Code project. Use /ux-writing-travel-good, /ocean-ink-design-system or /ux-quality-framework as slash commands.

unzip cuxedtech-plugin.zip
# then in Claude Code:
/ux-quality-framework
